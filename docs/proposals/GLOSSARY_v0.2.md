# Glossary v0.2 (provisional) — Two Point Campus Thai Mod

ผู้เสนอ: Claude (Translator) · วันที่: 2026-10-15 · ผู้อนุมัติ: Controller
ตามผลตรวจใน `docs/TRANSLATION_STYLE_REVIEW.md` ข้อ 5–6

**ยังไม่มีข้อความต้นฉบับจากเกม** คอลัมน์ "ตัวอย่างต้นฉบับ" จึงว่างทั้งหมดและจะเติมจากชุดที่ Controller สกัดเท่านั้น ห้ามใช้ตัวอย่างที่ผู้แปลสร้างเอง คอลัมน์บริบทระบุ **ขอบเขตการใช้ที่ต้องยืนยัน** ไม่ใช่การอ้างว่าเกมใช้คำนั้นอย่างไร

## ความหมายของสถานะ

| สถานะ | ความหมาย |
|---|---|
| `PROVISIONAL_APPROVED` | Controller รับเป็นค่าเริ่มต้นชั่วคราว ใช้ได้ แต่ทบทวนได้เมื่อเห็นต้นฉบับ |
| `UNRESOLVED` | ยังไม่ตัดสิน ห้ามใช้ค่าเริ่มต้น ให้ธง `AMBIGUOUS` เมื่อพบ |
| `NEEDS_CONTEXT` | ต้องมีรายการตามบริบทและตัวอย่างต้นฉบับก่อนอนุมัติ ห้ามบังคับใช้ |
| `CANDIDATE` | ตัวเลือกที่ผู้แปลเสนอ ไม่บังคับแทนที่ทั่วทั้งเกม ผู้แปลใช้ดุลพินิจตามบริบทและบันทึกใน `translator_note` |

## 5. ชื่อเฉพาะ (บันทึกตาม entity/key เมื่อได้รับอนุมัติ)

ยังไม่มีรายการ ตามข้อ 6 ของผลตรวจ: คงการสะกดต้นฉบับเป็นค่าชั่วคราว และบันทึกการตัดสินใจรายชื่อ/รายตัวละคร/รายห้อง/รายวิชาด้วย stable ID/key เมื่อ Controller ส่งชุดข้อความและอนุมัติ

## 6. กติกาการปรับ Glossary

- เพิ่มหรือเปลี่ยนสถานะโดย Controller อนุมัติเท่านั้น ผู้แปลเสนอผ่านไฟล์ใหม่หรือเวอร์ชันใหม่ ไม่แก้ทับรายการที่อนุมัติ
- รายการ `NEEDS_CONTEXT` ปิดได้ต่อเมื่อมีตัวอย่างต้นฉบับจาก Controller อย่างน้อยหนึ่งรายการต่อบริบท และมีคำแปลเฉพาะบริบทนั้น
- คอลัมน์ "ตัวอย่างต้นฉบับ" ใช้ stable ID ของข้อความที่ Controller ส่งเท่านั้น
