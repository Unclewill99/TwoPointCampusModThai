## 3. การเปรียบเทียบกับภาพหลักฐานจากเกมเดิม (`user-native-evidence.png` และ `02-campus-modal.png`)

ดูภาพเปรียบเทียบพร้อมป้ายกำกับอัตราส่วนขยาย (`2x NEAREST` / `4x NEAREST`) ได้ที่ [`02-labeled-comparison.png`](../../local/qa/WO-SARA-AM-001-REFERENCE/02-labeled-comparison.png):

1. **เปรียบเทียบคำว่า `ต่ำ` (`AM-ATOMIC` ใน `reference.html` เทียบกับ `ต่ำต้อย` ใน `user-native-evidence.png` และ `ต่ำเตี้ย` ใน `02-campus-modal.png`):**
   - **บนหน้าอ้างอิงเบราว์เซอร์ (`AM-ATOMIC` และ `AM-DECOMPOSED-REORDERED`):** นิคหิต (`ํ`) อยู่ชั้นล่างเหนือ `ต` และไม้เอก (`่`) ถูกยกขึ้นสู่ชั้นที่สองเหนือนิคหิต แยกออกเป็น 2 ระดับความสูงชัดเจน
   - **บนภาพหลักฐานจากเกมทั้งสองภาพ:**
     - ใน [`user-native-evidence.png`](../../local/qa/BUG-THAI-003/user-native-evidence.png) (`1542 x 1088`, ชุด `community-merge-006`, คำว่า `ต่ำต้อย` บริเวณครอป `(895, 375)–(1030, 430)`): **วงกลมนิคหิต (`ํ`) และขีดตั้งไม้เอก (`่`) วางซ้อนทับกันอยู่ที่ระดับความสูงชั้นล่างระดับเดียวกันเหนือ `ต`** (ไม่เกิดการยกไม้เอกขึ้นเป็นชั้นที่สองเหมือนใน `AM-ATOMIC` หรือการยกนิคหิตขึ้นเหมือนใน `AM-DECOMPOSED-ORIGINAL-ORDER`) ทำให้เห็นเป็นวงกลมที่มีขีดตั้งทะลุซ้อนทับกันตรงกลาง
     - ใน [`02-campus-modal.png`](../../local/qa/WO-FRESH-SMOKE-001-RESUME/02-campus-modal.png) (`1920 x 1080`, ชุด `fresh-translation-004`, คำว่า `ต่ำเตี้ย` บริเวณครอป `(1090, 415)–(1175, 452)`): แสดงพฤติกรรมเดียวกัน คือ **นิคหิตและไม้เอกของคำว่า `ต่ำ` ซ้อนทับกันอยู่ในระดับความสูงชั้นเดียวเหนือ `ต`**
2. **เปรียบเทียบกลุ่มควบคุมสระบน + วรรณยุกต์ (`TONE-REGRESSION` `ถี่` เทียบกับ `ที่ซึ่ง` / `ที่ชีวิต` / `เตี้ย` ในภาพเกม):**
   - ในทั้ง [`user-native-evidence.png`](../../local/qa/BUG-THAI-003/user-native-evidence.png) (คำว่า `ที่ซึ่ง` บริเวณครอป `(815, 315)–(915, 370)`) และ [`02-campus-modal.png`](../../local/qa/WO-FRESH-SMOKE-001-RESUME/02-campus-modal.png) (คำว่า `ที่ชีวิต` บริเวณครอป `(725, 415)–(805, 452)` และคำว่า `เตี้ย`): สระบน (`ี` / `ึ`) อยู่ชั้นล่างเหนือพยัญชนะ และวรรณยุกต์ (`่` / `้`) **ถูกยกขึ้นไปอยู่ชั้นที่สองเหนือสระบนได้อย่างชัดเจน** สอดคล้องกับทิศทางการวางสองชั้นใน `TONE-REGRESSION` (`ถี่`) บนหน้าอ้างอิงเบราว์เซอร์
   - ความแตกต่างนี้ชี้ให้เห็นเชิงประจักษ์ว่า ในภาพหน้าจอเกมทั้งสองชุด การซ้อนทับกันที่ระดับชั้นเดียวเกิดขึ้นจำเพาะกับลำดับสระอำที่มีวรรณยุกต์ (`ต่ำ` = `U+0E15 U+0E48 U+0E33`) ในขณะที่ลำดับสระบนปกติ + วรรณยุกต์ (`ที่`, `ซึ่ง`, `เตี้ย`) ในบรรทัดเดียวกันสามารถยกวรรณยุกต์ขึ้นชั้นบนได้
