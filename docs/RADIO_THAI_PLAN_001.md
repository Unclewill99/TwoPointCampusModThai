## 2. ความต่างจากชุด PA ที่ต้องแก้ก่อน

1. **ขนาดไฟล์**: PCM16 48k stereo ทั้งชุด ≈ 1.4 GB (ชุด PA ใช้ PCM ได้เพราะแค่ 35 นาที) → ต้องเข้ารหัส **Vorbis ใน FSB5** ด้วย FMOD `fsbankcl` (FMOD Studio ดาวน์โหลดฟรีบน Windows ต้องสมัครบัญชี FMOD — ผู้ใช้ทำ) แล้วให้ build script วาง FSB5 ที่ fsbankcl ผลิตลง .resource แทนที่จะเขียน PCM เอง ทางสำรอง: PCM mono 24 kHz ≈ 360 MB (ใหญ่แต่ใช้ได้ถ้า fsbankcl ติดปัญหา)
2. **เสียงไม่ใช่ลำโพง PA**: ใช้โทน "วิทยุ" (EQ เบา ๆ compressor) ไม่ band-pass แคบแบบ PA; ความดังอ้างอิงวัดจากคลิปต้นฉบับ (คาดราว −16…−18 LUFS ต้องวัดจริงก่อน)
3. **หลายตัวละคร**: ต้องคัดเลือกเสียง ElevenLabs 9 เสียง (ชาย 6 หญิง 3) ให้ต่างกันชัดและคงที่ตลอด 50+ คลิปต่อคน; คลิปยาว 20–45 วินาที → ตั้งค่า stability สูง ใช้ seed คงที่ และแท็กอารมณ์ต่อตัวละคร (เช่น Harrison `[excited]`, Nigel `[posh]`/`[sarcastic]`, Maggie `[nervous]`)
4. **โฆษณาและ sting มีเพลงประกอบ**: ไม่สามารถทับทั้งคลิปด้วย TTS เฉย ๆ ต้องเลือก (ดูข้อ 5)
5. **ชื่อเฉพาะ**: Two Point County, Hogsport, Mitton, Smogley, Crumley, Cheesy Gubbins ฯลฯ → เพิ่มใน `tannoy-pronounce.json` (ใช้ร่วมกัน) และกำหนดคำทับศัพท์ให้ตรงกับคำบรรยายในคลัง 007

## 3. ลำดับงาน (แต่ละขั้นมีจุดหยุดให้ผู้ใช้ตรวจ)

**R0 — เตรียม (ไม่ใช้เครดิต, 1 รอบงาน)**
- ถอดรหัส 342 คลิปจาก bundle (UnityPy) วัดความยาว/ความดัง ระบุคลิปที่มีเพลงประกอบ → `local/audio/radio-survey-001/`
- สร้าง `local/review/radio-lines-thai.json` จากคลัง 007 (ตัดชื่อผู้พูด แยกคลิปที่มีหลายผู้พูด) + `radio-cast.json` (ตัวละคร → voice id, แท็ก, ค่า stability)
- ผู้ใช้ติดตั้ง FMOD Studio (fsbankcl) บน Windows; Claude เขียน `tools/fsb_vorbis_windows.py` ห่อ fsbankcl และ `tools/build_radio_thai_001.py` (ฐานจากชุด PA แต่รับ FSB5 Vorbis จากภายนอก)
- **radio-thai-001 (probe เทคนิค)**: นำคลิปต้นฉบับ 2 คลิปมาถอด → เข้ารหัส Vorbis ใหม่ด้วย fsbankcl → บรรจุกลับ → ทดสอบในเกมว่าเล่นได้ ขนาดใกล้เดิม (ยังไม่มีเสียงไทย)

**R1 — คัดเสียงและนำร่อง (≈ 1.5k เครดิต)**
- Claude เสนอเสียง ElevenLabs 2–3 ตัวต่อตัวละครหลัก (ประโยคตัวอย่างสั้น 1 ประโยค/เสียง ≈ 40 เสียง × 60 ตัวอักษร ≈ 1.1k เครดิต) ผู้ใช้ฟัง mp3 แล้วเลือก
- Host_Intro 10 คลิป (Felicity ≈ 2.3k ตัวอักษร ≈ 1k เครดิต) → โทนวิทยุ + ความดัง → Vorbis → **radio-thai-002** ทดสอบในเกม (เปิดรายการวิทยุในเกมแล้วฟัง)

**R2 — ผลิตเป็นชุดตามตัวละคร (รอบเครดิตนี้ ≈ 28k)**
- ลำดับ: Felicity ที่เหลือ → Hugh → Maggie → Wanda → DJ Shorts → Harrison → Nigel (≈ 28k) หยุดเมื่อเครดิตใกล้หมด; Ricky (≈ 8.4k) รอหลัง 26 พ.ย.
- build ทีละตัวละคร (radio-thai-003…) ให้ผู้ใช้ฟังจริงและรายงานคำอ่านเพี้ยนเป็นรอบ ๆ เหมือนชุด PA; คลิปที่ยังไม่ทำคงเสียงอังกฤษเดิม (ชุดนี้ผสมภาษาได้เพราะแต่ละคลิปอิสระ)

**R3 — โฆษณา / sting / ตัวประกอบ (หลัง 26 พ.ย.)** เลือกหนึ่งทาง:
- (ก) **คงอังกฤษ** สำหรับโฆษณาและ sting ที่มีเสียง — ง่ายที่สุด คำบรรยายไทยมีอยู่แล้ว
- (ข) สังเคราะห์เสียงพูดไทยแล้ว **ผสมบนเพลงประกอบเดิม** ด้วยการแยกเสียงร้อง/ดนตรี (demucs บน Windows) — คุณภาพไม่แน่นอน ใช้เวลามาก
- (ค) ใส่เสียงไทยทับโดยไม่มีเพลง — ฟังดูจืดกว่าเดิม
- ข้อเสนอ: เริ่มด้วย (ก) ประเมิน (ข) จากตัวอย่าง 1 โฆษณาเมื่อเครดิตเหลือ

**R4 — ปิดงาน**: ใส่ชุดวิทยุใน Install/Uninstall_Thai_Mod.bat, เอกสาร RADIO_THAI_001.md, เช็คพอยต์

## 4. ความเสี่ยง
- fsbankcl ผลิต FSB5 Vorbis ที่เกมอาจต้องการ flag/เวอร์ชันเฉพาะ → ทดสอบใน R0 ก่อนใช้เครดิต
- เสียง TTS ยาว 30–40 วินาที อาจเพี้ยนกลางคลิป → ตัดบทเป็นประโยคแล้วต่อ หรือ regen เฉพาะคลิป
- เครดิตไม่พอทั้งชุดในรอบเดียว (วางแผนข้าม 2 รอบไว้แล้ว)
- การเล่นวิทยุในเกมอาจต่อคลิปเป็นรายการ (intro → sting → segment) ถ้าคลิปไทยสั้น/ยาวต่างมากอาจมีช่วงเงียบ แต่ไม่ทำให้ค้าง
